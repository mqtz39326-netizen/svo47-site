# Меры поддержки участников СВО — Ленинградская область

Информационный сайт-навигатор мер социальной поддержки участников СВО и членов их семей
в Ленинградской области. React + TypeScript + Vite + Tailwind CSS.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # сборка в dist/ (статический сайт)
npm run preview  # предпросмотр сборки
```

## Как обновлять данные о мерах поддержки

Весь контент лежит в `src/data/` и правится без изменения кода страниц:

| Файл | Что содержит |
|---|---|
| `src/data/measures.ts` | Каталог мер: название, описание, размер выплаты, НПА, пошаговая инструкция, документы, контакты, ссылка на источник, дата актуализации |
| `src/data/institutions.ts` | Учреждения для страницы «Где получить» (адреса, телефоны, часы работы) |
| `src/data/faq.ts` | Вопросы и ответы |
| `src/data/links.ts` | Полезные ссылки |

### Чтобы добавить новую меру

1. Откройте `src/data/measures.ts`.
2. Скопируйте любой существующий объект в массиве `MEASURES` и отредактируйте поля:
   - `id` — уникальный латинский slug (появится в адресе страницы `#/measure/<id>`);
   - `category` — одна из: `payments`, `health`, `housing`, `transport`, `education`, `work`, `bereaved`, `other`;
   - `recipients` — массив из: `participant`, `family`, `bereaved`;
   - `amountValue` — число для сортировки по размеру выплаты (0 для неденежных мер);
   - `source` и `updated` — ссылка на официальный источник и дата проверки (обязательно).
3. Сохраните файл — сайт обновится автоматически. Править компоненты не нужно.

### Чтобы изменить телефон горячей линии

Отредактируйте константы `HOTLINE` / `HOTLINE_TEL` в `src/components/Layout.tsx`.

## Структура

- `src/pages/` — страницы: главная, каталог, карточка меры, «Где получить», FAQ, ссылки;
- `src/components/` — поиск с автоподсказками, селектор помощи (квиз), версия для слабовидящих, форма «Задать вопрос»;
- `src/context/` — настройки доступности (размер шрифта, контраст, отключение изображений).
